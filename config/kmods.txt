# Kernel modules baked into the barebone image.
#
# Why these and nothing else: kmod-* packages are locked to the kernel by
# vermagic (6.18.44 SMP mod_unload aarch64). They cannot be fetched with apk
# later -- a module from the feed is built for a different kernel and will not
# load. Everything userspace (openclash, passwall, mwan3, sqm, wol and their
# cores) IS installable later, so it is deliberately left out.
#
# This list is identical to the 76 kmods in the hardware-validated v4 image,
# which already carried openclash + mwan3 + sqm. Format: <package>  # reason
#
